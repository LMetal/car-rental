# 🚗 Car Rental – Demo Project  

Progetto universitario realizzato per il corso **Programming Methodologies for the Web** presso **UniUpo**.  
Si tratta di una **web app per la gestione di un servizio di noleggio auto**, con autenticazione utenti e dipendenti, sviluppata con tecnologie moderne lato front-end e back-end.  

🌐 **Demo online (unstable):** [https://car-rental.cyclic.app](https://car-rental.cyclic.app)

## 🛠️ Tecnologie utilizzate  

**📚 Librerie principali**
- SSR – Server-Side Rendering  
- Passport.js – Autenticazione  
- Moment.js – Gestione date e orari  
- SQLite – Database leggero e integrato  
- Bcrypt – Hashing delle password  
- Bootstrap – Stile e interfaccia responsive  

**💻 Linguaggi**
- HTML / CSS – Struttura e stile delle pagine  
- JavaScript (Node.js) – Logica applicativa lato server  
- EJS (Embedded JavaScript) – Template engine  

---

## 🚀 Funzionalità principali
- Registrazione e login utenti/dipendenti  
- Autenticazione sicura con Passport e Bcrypt  
- Gestione auto e prenotazioni (CRUD)  
- Interfaccia responsive grazie a Bootstrap  
- Integrazione database SQLite
